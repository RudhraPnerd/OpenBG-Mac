# OpenBG - Mac



OpenBG Mac is a great and useful tool if you want to change your wallpaper to a different one that isn't on your Mac. Whether it’s a glitch or the wallpaper isn’t
compatible on your Mac.

> [!IMPORTANT]
> This project requires MacOS and Python 3.14
